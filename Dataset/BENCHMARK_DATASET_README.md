# Benchmark Dataset Documentation

## Overview
This dataset is designed for evaluating the NodeRAG system against a baseline LLM (Gemma 3 12B) for job application Q&A tasks.

**File:** `benchmark_dataset_20260204_232109.csv`

---

## Dataset Structure

### Total Records
- **330 rows** total
- **10 unique users** (user_36 to user_45)
- **3 job descriptions** per user (randomly selected)
- **11 questions** per job-resume pair

### Columns (14 total)

#### Original Columns from Testing Dataset
1. **Job Title** - The job title (e.g., "Backend Developer")
2. **Job Description** - Full job description text
3. **Question** - The question being asked
4. **Resume File Name** - PDF filename of the resume
5. **Latex_Code** - LaTeX formatted resume content
6. **LLM Answer** - Answer generated by baseline LLM (Gemma 3 12B)
7. **Tokens** - Token count for baseline LLM response
8. **Time** - Time taken for baseline LLM response (seconds)

#### New Columns Added
9. **User ID** - User identifier (user_36 to user_45)
10. **Category** - Question category (see categories below)
11. **NodeRAG Answer** - Answer from NodeRAG system (empty - to be filled)
12. **NodeRAG Tokens** - Token count for NodeRAG response (empty - to be filled)
13. **NodeRAG Time** - Time taken for NodeRAG response (empty - to be filled)
14. **Source** - Question source: `csv` (from original dataset) or `benchmark` (additional questions)

## Usage

### For Benchmarking NodeRAG

1. **Read the dataset:**
   ```python
   import pandas as pd
   df = pd.read_csv('benchmark_dataset_20260204_232109.csv')
   ```

2. **For each row:**
   - Extract: `User ID`, `Question`, `Job Description`
   - Call NodeRAG system with these inputs
   - Record: Answer, Tokens, Time
   - Update: `NodeRAG Answer`, `NodeRAG Tokens`, `NodeRAG Time`

3. **Compare results:**
   - For CSV source rows: Compare NodeRAG vs baseline LLM
   - Group by category for detailed analysis
   - Calculate metrics: latency, token usage, answer quality

### Evaluation Metrics

- **Latency:** `NodeRAG Time` vs `Time` (for CSV rows)
- **Token Efficiency:** `NodeRAG Tokens` vs `Tokens` (for CSV rows)
- **Answer Quality:** Manual/automated evaluation of `NodeRAG Answer` vs `LLM Answer`
- **Category Performance:** Break down metrics by question category
- **User Consistency:** Check variance across different users
