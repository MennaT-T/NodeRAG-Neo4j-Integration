**Q7 (universal):** *"Why are you interested in joining our company?"*

### Job-Specific Questions (Q1–Q5):

**Backend Developer**
1. What backend languages and frameworks have you used, and which are you strongest in?
2. Describe a backend system you built or improved—what were the main challenges and how did you solve them?
3. How do you design and document RESTful (or GraphQL) APIs for maintainability and scalability?
4. What is your approach to database schema design and optimizing queries for performance?
5. How do you ensure backend reliability (testing, monitoring, error handling) in production?

**Database Administrator**
1. What database platforms (e.g., PostgreSQL, MySQL, SQL Server) have you administered in production?
2. How do you design backup, restore, and disaster recovery plans, and how often do you test them?
3. Describe a time you diagnosed and fixed a slow query or performance bottleneck—what steps did you take?
4. What is your approach to securing databases (roles/permissions, encryption, auditing)?
5. How do you handle capacity planning and scaling for growing data and traffic?

**DevOps Engineer**
1. Which CI/CD tools and workflows have you implemented, and what outcomes did they achieve?
2. How do you approach infrastructure as code (e.g., Terraform/CloudFormation) and environment consistency?
3. Describe your experience with containerization and orchestration (Docker/Kubernetes) in production.
4. How do you monitor systems and respond to incidents (alerting, on-call, postmortems)?
5. What practices do you use to improve deployment safety (canary releases, rollbacks, feature flags)?

**Django Developer**
1. How many years have you worked with Django, and what types of products have you built with it?
2. Describe a Django project you contributed to—what was your role and what impact did your work have?
3. How do you structure Django apps and manage settings for multiple environments (dev/staging/prod)?
4. What is your approach to performance tuning in Django (ORM optimization, caching, background jobs)?
5. How do you ensure code quality in Django projects (tests, linting, code reviews)?

**Flutter Developer**
1. What Flutter apps have you built, and what parts did you personally own end-to-end?
2. How do you manage state in Flutter (e.g., Bloc, Provider, Riverpod), and why do you prefer that approach?
3. Describe a challenging UI/UX or animation you implemented in Flutter—how did you build it?
4. How do you handle app performance and debugging (profiling, memory, jank) in Flutter?
5. What is your experience integrating Flutter apps with REST APIs, authentication, and local storage?

**Full Stack Developer**
1. Which frontend and backend technologies are you most experienced with, and what have you built using them?
2. Describe a full-stack feature you delivered—how did you coordinate API design, UI, and deployment?
3. How do you ensure security across the stack (auth, authorization, input validation, OWASP risks)?
4. What is your approach to testing (unit/integration/e2e) for both frontend and backend components?
5. How do you optimize performance for a web application (frontend loading, backend latency, database)?

**Java Developer**
1. What Java versions and frameworks (e.g., Spring Boot) have you used in production?
2. Describe a Java service you built or maintained—how did you ensure scalability and reliability?
3. How do you handle concurrency and thread-safety in Java applications?
4. What is your approach to writing clean, testable Java code (design patterns, testing tools)?
5. Tell us about a time you improved performance in a Java application—what did you change and why?

**JavaScript Developer**
1. What JavaScript frameworks/libraries (e.g., React, Vue, Angular) have you worked with, and at what depth?
2. Describe a complex UI you built in JavaScript—how did you manage state, performance, and accessibility?
3. How do you organize and maintain a large JavaScript codebase (linting, formatting, modularization)?
4. What is your experience with API integration, authentication, and error handling on the client side?
5. How do you test JavaScript applications (unit, integration, e2e), and which tools have you used?

**Machine Learning**
1. What is your experience in machine learning (projects, models, and the business problems you solved)?
2. Which ML frameworks and tools (e.g., scikit-learn, PyTorch, TensorFlow) are you most comfortable with?
3. How do you evaluate model performance and handle issues like overfitting, data leakage, or class imbalance?
4. Describe a time you deployed an ML model to production—how did you monitor and iterate on it?
5. How do you approach data preprocessing and feature engineering for real-world datasets?

**Network Administrator**
1. What types of networks have you managed (size, topology), and what were your main responsibilities?
2. How do you troubleshoot network connectivity issues—what tools and steps do you use?
3. Describe your experience with firewalls, VLANs, routing, and switching in production environments.
4. What is your approach to network security (access controls, monitoring, patching, incident response)?
5. How do you document and maintain network configurations to support reliability and audits?

**Node.js Developer**
1. What Node.js frameworks (e.g., Express, NestJS) have you used, and what have you built with them?
2. Describe a Node.js API or service you developed—how did you handle validation, errors, and logging?
3. How do you manage asynchronous flows in Node.js (promises, async/await, queues), and avoid common pitfalls?
4. What is your experience with databases in Node.js (ORMs, query builders, performance tuning)?
5. How do you ensure a Node.js application is production-ready (tests, monitoring, security, deployments)?

**PHP Developer**
1. What PHP frameworks (e.g., Laravel, Symfony) have you used, and what kinds of applications did you build?
2. Describe a PHP project you worked on—what was the most challenging part and how did you address it?
3. How do you structure PHP code for maintainability (architecture, SOLID principles, dependency management)?
4. What is your experience with database design and query optimization in PHP applications?
5. How do you handle security in PHP apps (validation, authentication, preventing SQL injection/XSS)?

**Software Engineer**
1. Why are you interested in this Software Engineer role, and what do you hope to accomplish here?
2. Describe a project you're proud of—what was your contribution and what impact did it have?
3. How do you approach debugging and root-cause analysis when a production issue occurs?
4. What practices do you follow to write maintainable code (testing, reviews, documentation)?
5. How do you collaborate with product/design/QA stakeholders to deliver features effectively?

**Wordpress Developer**
1. What WordPress projects have you built (themes, plugins, custom blocks), and what was your role?
2. How do you approach performance optimization in WordPress (caching, images, queries, hosting)?
3. Describe your experience with PHP and customizing WordPress beyond off-the-shelf plugins.
4. How do you handle security and updates in WordPress sites (hardening, backups, plugin management)?
5. What is your experience integrating WordPress with third-party services (APIs, payments, CRM, analytics)?

**iOS Developer**
1. What iOS apps have you built, and which features/components did you own end-to-end?
2. Which iOS technologies do you use most (Swift, SwiftUI, UIKit), and why?
3. Describe a challenging bug or performance issue you solved in an iOS app—how did you debug it?
4. How do you structure iOS codebases (architecture patterns like MVVM/VIPER) for maintainability?
5. What is your experience with testing and releasing iOS apps (unit/UI tests, App Store process, CI/CD)?
